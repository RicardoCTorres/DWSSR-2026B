# 📝Convecion de iconos para comits

| Icono | Tipo | Descripción y Uso Común |
| --- | --- | --- |
| ✨ | `feat` | Nueva funcionalidad o módulo para el usuario. |
| 🐛 | `fix` | Corrección de un bug o error en el sistema. |
| 📝 | `docs` | Cambios únicamente en la documentación (ej. `README.md`). |
| 💄 | `style` | Formato, espacios, estilos CSS o UI sin alterar lógica de negocio. |
| ♻️ | `refactor` | Reestructuración de código sin corregir bugs ni añadir features. |
| ⚡️ | `perf` | Mejora de rendimiento, optimización de consultas o carga. |
| ✅ | `test` | Añadir, actualizar o corregir pruebas unitarias o de integración. |
| 🔧 | `chore` | Tareas rutinarias, configuración de herramientas o scripts de compilación. |
| 📦 | `build` | Modificaciones que afectan el sistema de empaquetado o dependencias (ej. `npm`, `vite`). |
| 👷 | `ci` | Cambios en la integración o despliegue continuo (ej. GitHub Actions, Docker). |
| ⏪️ | `revert` | Revertir un commit previo. |
| 🔒️ | `security` | Parche de seguridad o corrección de vulnerabilidades. |
